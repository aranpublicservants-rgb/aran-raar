# Racialized Executives Network

Bilingual information and data resource for racialized executives in Canada’s federal public service.

The website includes executive representation, racialized subgroup figures, career progression research, staffing movements, employee survey comparisons and a contribution form. The statistical sources, reference periods and interpretation notes accompany each series.

The HTML page contains its interactive data. Companion CSV and JSON files provide downloadable source tables. Language can be selected with `?lang=en` or `?lang=fr`.

The contribution form processes responses in the visitor’s browser. Visitors review their response and open a prepared email addressed to the network contact. Sending requires the visitor’s email application. Copy and text download options are available. The website does not store form responses.

The website is hosted on GitHub Pages. It is an employee network resource and is not a Government of Canada departmental website.
