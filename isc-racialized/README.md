# Racialized employees at ISC / Employés racisés à SAC

A bilingual ARAN data resource for Indigenous Services Canada. The website is independent of the Government of Canada.

Une ressource de données bilingue du RAAR sur Services aux Autochtones Canada. Ce site est indépendant du gouvernement du Canada.

## Contents / Contenu

- TBS representation and departmental workforce availability for 2021 to 2025, with published expected counts and racialized subgroups.
- PSC ISC applicants, employees, hires, promotions and acting appointments. The source contains 2025–26 applicants and other measures through 2024–25.
- All 207 PSES 2024 question items for the 25 included racial identity and comparison groups, with public service comparators, response counts, raw response categories and source summary measures.
- Published racialized and Black employee PSES results across 11 ISC branches.
- PSC Staffing and Non-Partisanship Survey response distributions for ISC in 2023 and 2025, including racialized subgroups.
- Complete CSV extracts, structured JSON and source provenance.

Les mêmes fonctions et explications sont disponibles en français. Les noms des groupes, les questions et les options de réponse conservent les libellés des sources ou utilisent une traduction indiquée dans l’interface.

## Open or publish / Ouvrir ou publier

Open `index.html` in a browser. All interactive data, styles and code are embedded. No build, server, external fonts, API key or account is required. Downloads work offline through the embedded data.

For GitHub Pages, publish the `main` branch from the repository root. The `.nojekyll` file disables Jekyll processing. Keep the CSV and JSON files beside `index.html` for direct file downloads.

Ouvrez `index.html` dans un navigateur. Les données interactives, les styles et le code sont intégrés. Aucune compilation, aucun serveur, aucune police externe, aucune clé API et aucun compte ne sont nécessaires. Les téléchargements fonctionnent hors ligne à partir des données intégrées.

Pour GitHub Pages, publiez la branche `main` à partir de la racine du dépôt. Le fichier `.nojekyll` désactive Jekyll. Conservez les fichiers CSV et JSON avec `index.html` pour les téléchargements directs.

## Interpretation / Interprétation

TBS and PSC employee populations differ. Appointment shares are not individual promotion rates. Survey counts and workforce headcounts differ. PSES and PSC survey definitions are separate. Suppressed and unavailable cells remain unavailable. Differences between groups do not by themselves establish discrimination.

Les populations du SCT et de la CFP diffèrent. Les pourcentages des nominations ne sont pas des taux individuels de promotion. Les nombres de réponses aux sondages diffèrent des effectifs. Les définitions du SAFF et des sondages de la CFP sont distinctes. Les valeurs supprimées et indisponibles demeurent indisponibles. Les écarts entre groupes ne prouvent pas à eux seuls l’existence de discrimination.

Sources were reviewed on 6 November 2026. The reference periods vary by dataset. `sources.json` records the official sources and the revisions of the ten reviewed ARAN repositories. Private Google Drive files are not made public by this website.

Les sources ont été examinées le 6 novembre 2026. Les périodes de référence varient selon le jeu de données. `sources.json` consigne les sources officielles et les versions des dix dépôts du RAAR examinés. Ce site ne rend pas publics les fichiers privés de Google Drive.
