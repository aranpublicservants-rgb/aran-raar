# ARAN / RAAR

Bilingual public website for the Anti-Racism Ambassadors Network / Réseau des ambassadeurs de l’antiracisme.

Website: https://aranpublicservants-rgb.github.io/aran-raar/

Working draft: https://aranpublicservants-rgb.github.io/aran-raar/working-draft.html

The site provides network information, community links, the IDEAA-nomics podcast, a searchable equity resource directory, volunteer email forms and lessons learned contributions. / Le site présente le réseau, ses liens communautaires, le balado IDEAA-nomics, un répertoire de ressources sur l’équité, le bénévolat par courriel et les contributions de leçons retenues.

Reading controls support text up to 200%, high contrast, wider text spacing, a simpler layout, visible links and reduced motion. Read-aloud uses browser voices when available. Native dialogs and keyboard search support keyboard navigation. / Les commandes permettent d’agrandir le texte jusqu’à 200 %, d’augmenter le contraste et l’espacement, de simplifier la mise en page, de souligner les liens et de réduire les mouvements. La lecture à voix haute utilise les voix du navigateur lorsqu’elles sont disponibles.

Visitors can save resource choices on their device, export a reading list and download bilingual meeting, action, accessible-event and lessons templates. Core pages and templates can be read offline after the site has been visited and its offline files saved. / Les visiteurs peuvent enregistrer leurs choix de ressources sur leur appareil, télécharger une liste de lecture et utiliser des modèles bilingues. Les pages et les modèles peuvent être consultés hors ligne après une visite et leur enregistrement par le navigateur.

The shared draft reader is served from GitHub Pages. It retrieves consented contributions from the contribution service, distinguishes an empty draft from a connection failure, and offers Word, HTML, text and print exports. A three-step form supports optional local draft saving, confirmed receipts, idempotent retries and withdrawal codes. An email alternative prepares a message for review and sending; emailed material requires network review before it is added. / Le lecteur du document de travail est hébergé sur GitHub Pages. Il récupère les contributions consenties, distingue un document vide d’une erreur de connexion et offre des versions Word, HTML, texte et imprimables. Un formulaire en trois étapes permet de conserver un brouillon local, de recevoir un reçu et de retirer une contribution.

Volunteer messages are addressed to aranpublicservants@gmail.com and sent by the visitor from their own email account. / Les courriels de bénévolat sont adressés à aranpublicservants@gmail.com et envoyés par les visiteurs à partir de leur compte.

The static pages use no advertising or analytics trackers. Existing network and data subdirectories remain available. / Les pages n’utilisent pas de traceurs publicitaires ou d’analyse. Les sous-répertoires existants restent disponibles.
