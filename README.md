# ARAN / RAAR

Public website for the Anti-Racism Ambassadors Network / Réseau des ambassadeurs de l’antiracisme.

- English: https://aranpublicservants-rgb.github.io/aran-raar/
- Français : https://aranpublicservants-rgb.github.io/aran-raar/fr.html

The page includes the network overview, community links, a searchable equity resource directory, IDEAA-nomics podcast information, a volunteer email form and a lessons learned contribution form. / La page présente le réseau, les liens communautaires, un répertoire de ressources sur l’équité, le balado IDEAA-nomics, un formulaire de bénévolat par courriel et un formulaire de leçons retenues.

The volunteer form prepares an email addressed to aranpublicservants@gmail.com. Visitors review and send the message from their own email account. / Le formulaire de bénévolat prépare un courriel adressé à aranpublicservants@gmail.com. Les visiteurs vérifient et envoient le message à partir de leur compte.

Consented lessons are stored by the contribution service and assembled into a bilingual working draft. Contributors receive a withdrawal code. The draft offers text and HTML exports and a print-to-PDF option. / Les leçons accompagnées d’un consentement sont conservées par le service de contributions et regroupées dans un document de travail bilingue. Un code permet de retirer une contribution. Le document offre des versions texte et HTML, ainsi que l’impression en PDF.

The static page has no build dependencies. index.html and fr.html share styles.css, app.js and the existing ARAN logo. Existing network and data subdirectories remain separately available.
